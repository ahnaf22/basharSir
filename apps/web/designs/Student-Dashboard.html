WHAT CHANGED VS THE OLD DASHBOARD
1. Four identical stat tiles with coloured side rails → one "ledger" strip; the streak gets the most room because it drives daily return.
2. Internal codes never reach the student: no CHECK_PREREQUISITES, BADGE_SCHOLAR_STARTER, NCTB-2026-BM-v1.0, STU-2026-DEMO. Show human words ("শুরুর আগে: আগের পড়া একটু ঝালাই").
3. One clear next action: the chalk-white card. Everything else is quiet.
4. 0% bars are replaced by an empty state that says how to fill them.
5. Greeting includes a one-line summary sentence, so the page is understood in 3 seconds.
